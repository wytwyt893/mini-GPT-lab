### 验证与实际 Shape

环境验证仅使用普通矩阵乘法和自动求导，并非实现 Attention 或其他 GPT 模块：

```text
x:          [2, 3]  float32, CPU
weight:     [3, 4]  float32, CPU，全部为 1
y = x @ W:  [2, 4]
loss:       标量，y.sum()
x.grad:     [2, 3]，每个元素为 4
```

`x=[[0,1,2],[3,4,5]]`，输出两行分别全为 3 和 12；每个输入元素参与 4 个输出求和，因此对 `loss` 的梯度为 4。以这一小例子验证 CPU 前向和反向传播。
